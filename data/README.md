# Data directory

Notebook 01 downloads the required public-use NHANES August 2021--August 2023 XPT files into `data/raw/` and creates processed analytical files in `data/processed/`.

Raw and processed participant-level data are intentionally excluded from version control. Empty directories are retained with `.gitkeep` files. Use only the official NCHS public-use files and comply with the NCHS Data User Agreement.
