# Interpretable Machine Learning and Fairness in Diabetes Prediction

This repository contains code for a seminar research paper on interpretable machine learning and fairness in healthcare.

The project uses public NHANES data to compare two diabetes prediction targets:

1. self-reported physician-diagnosed diabetes
2. HbA1c-based diabetes status

The main question is whether interpretable models explain biological diabetes risk, or whether they also reveal unequal access to diagnosis and healthcare.

## Data

The data are downloaded from the public NHANES website. Raw data files are not stored in this repository. The notebook `01_load_nhanes_data.ipynb` downloads and prepares the required files.
